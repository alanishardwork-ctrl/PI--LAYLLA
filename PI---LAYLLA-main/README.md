LAYLLA – Loja de Bijuterias

Sobre o projeto

A LAYLLA é um site fictício de bijuterias desenvolvido como projeto educacional, com o objetivo de colocar em prática os conhecimentos adquiridos em desenvolvimento web. O projeto simula uma loja online de joias e acessórios, permitindo a navegação entre páginas e a visualização dos produtos.

Objetivo

O objetivo do projeto é aplicar conhecimentos de HTML e CSS na criação de um site organizado, responsivo e criativo, simulando uma loja virtual.

Tecnologias utilizadas

· HTML
· CSS
· Bootstrap

Funcionalidades

· Página inicial;
· Catálogo e divulgação de produtos;
· Carrossel de imagens para divulgação dos produtos na página inicial;
· Página sobre a loja;
· Página de contato;
· Navegação entre páginas;
· Menu expansível e recolhível utilizando o componente Offcanvas;
· Barra lateral flexível utilizando Bootstrap;
· Tabela informativa sobre a qualidade dos produtos;
· Formulário simulado para contato;
· Interface responsiva, adaptada para diferentes tamanhos de tela.
